# 🚀 BizTab Payment Gateway Simulator

## 📌 Project Overview

This project was developed as part of the **BizTab Consulting Internship Assignment**.

The objective was to select one module from the **Order-to-Delivery (O2D)** business process and build a working technical demonstration. For this implementation, the **Payment Processing Module** was selected and developed as a Payment Gateway Simulator.

The application demonstrates secure payment processing through validation checks, OTP authentication, transaction handling, and exception management.

---

## 🎯 Assignment Objective

To understand the complete Order-to-Delivery business workflow and implement a technical demo of one critical module.

Selected Module:

**Payment Processing**

---

## 🏢 Order-to-Delivery Business Flow

```text
Customer Places Order
        ↓
Order Validation
        ↓
Inventory Stock Check
        ↓
Order Confirmation
        ↓
Payment Processing
        ↓
Order Fulfillment
        ↓
Shipment Initiation
        ↓
Logistics / Transportation
        ↓
Delivery to Customer
        ↓
Delivery Confirmation
```

This project focuses on the **Payment Processing** stage of the workflow.
